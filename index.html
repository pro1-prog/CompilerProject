What makes MiniLang different

Most languages only check types. MiniLang also checks values.

Range types

Declare int[0..100]. The compiler works out the possible range of every expression and compares it with your declaration.

Overflow and zero checks

Numbers are 32-bit. A check is added only where overflow or division by zero cannot be ruled out. Try 13 in the factorial example.

Safer by design

Every variable needs a starting value, types never mix silently, braces are required, and for loops always finish.

A compiler that explains

Inside while (n > 0) it knows n ≥ 1, so 100 / n needs no check. The Report tab counts the checks it removed.

How the compiler works

Your code passes through six stages. The tabs on the right show the results of the middle ones.

ParserChecks grammar, builds a tree

Virtual machineRuns the code and enforces checks
